# ensaio — repo guidance

This repo is the public engine. It holds mechanism only: the `Ensaio` CRD
(`ensaio.pleme.io`) and its controller, the interpreter, certification
receipts, visita, `ensaio-mcp` and `utsuroi-lifecycle`. A deployment's facts
(its environments, trial specs, charts, cluster names) live in that
deployment's own overlay repo, which depends on this one by git.

- The controller reconciles only `Ensaio` objects whose `spec.scope` equals
  `ENSAIO_SCOPE`, and refuses to start when it is unset.
- `deploy/crds/ensaio-crd.yaml` is generated by `ensaio print-crd`;
  `catalog_reflection` fails when it drifts.
- Every name in this tree is generic. Never commit a deployment's cluster,
  tenant or vendor name here.

Canonical design doc: `theory/ENSAIO.md` in the pleme-io org.
